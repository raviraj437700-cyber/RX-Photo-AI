# RX Photo AI

Android starter app with two modes:
- **Photo Enhance** — gentle sharpening and colour adjustments.
- **Thumbnail Enhance** — stronger sharpening, contrast and saturation.

## Current features
- Choose an image with Android's document picker.
- Preview the image.
- Apply on-device image filters.
- Save the result to Pictures / RX Photo AI.
- Build a debug APK using GitHub Actions.

## Important limitation
This first version uses classic image-processing filters. It is **not yet a Remini-equivalent AI restoration model** and cannot reliably reconstruct missing facial detail or preserve every tiny thumbnail letter. A later version can integrate a compatible on-device super-resolution model after licensing, app size and device performance are evaluated.

## Get the APK
1. Open the **Actions** tab in this repository.
2. Select **Build RX Photo AI APK**.
3. Open the completed workflow run.
4. Download the **RX-Photo-AI-debug-apk** artifact.
